# Inzare — сайт производителя чеченских минеральных вод

Корпоративный сайт бренда Inzare: продукция (минеральная вода и напитки), производство, история компании, контакты. Светлая и тёмная темы, адаптивная вёрстка, несколько вариантов дизайна главной.

**Демо:** https://harmonious-lily-44460d.netlify.app

## Стек
React + Vite (одностраничное приложение), шрифт Manrope, изображения в WebP с адаптивными размерами (400/800/полный).

## Что в репозитории
Готовая сборка сайта в том виде, в каком она опубликована на Netlify:
- `index.html`, `assets/` — сборка Vite (JS, CSS, шрифты, изображения)
- `assets/source/` — медиаматериалы бренда, которые использует сайт (фото, видео, PDF-документы)
- `_redirects` — правило Netlify для одностраничного приложения

Локально: `npx serve -s .`
